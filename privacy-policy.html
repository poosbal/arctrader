Privacy Policy

ARC Trader Simple Analyzer

ARC Trader Simple Analyzer is a Chrome extension built to help users analyze ARC Raiders marketplace listings on MetaForge and open trade negotiations more quickly.

Information We Access

The extension accesses marketplace information on metaforge.app that is necessary for its core features, including:

  • listing information shown on the MetaForge ARC Raiders marketplace
  • item names, listing types, prices, quantities, and trade-related page data
  • page state needed to open or continue a trade negotiation

How Information Is Used

The extension uses this information only to provide its core functionality, including:

  • rendering analyzer views and marketplace summaries
  • calculating deal comparisons and trends
  • opening the correct trade negotiation for a selected listing
  • storing local extension state such as cached snapshots and UI preferences

Data Storage

The extension stores necessary working data locally in the browser using Chrome extension storage. This is used for cached marketplace snapshots, filters, refresh state, and other analyzer settings.

Data Sharing

The extension does not sell personal data and does not use personal data for advertising. It does not intentionally transmit personal data to the developer for analytics, marketing, profiling, or resale.

Third-Party Services

The extension works with MetaForge pages and MetaForge marketplace endpoints because that is the service it is built to support. Any interaction with MetaForge remains subject to MetaForge's own terms and privacy practices.

User Control

Users can stop all extension activity at any time by disabling or removing the extension in Chrome. Removing the extension also removes its locally stored Chrome extension data.

Changes

This policy may be updated if the extension's functionality changes. Updated versions should be published alongside future releases.
